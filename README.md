# Assignment 1 - HTML & CSS Basics

**Name:** Narges  
**Course:** Web Technologies

## Objective
The objective of this assignment was to practice the basic concepts of HTML and CSS and create a simple webpage.

## Part 1 - Introduction to HTML
I created the basic HTML structure and used headings, paragraphs, ordered and unordered lists, images, links, and a button.

## Part 2 - Intermediate HTML
I created a table, used emojis, and added a form containing name, email, favorite color, and submit fields.

## Part 3 - Introduction to CSS
I used inline, internal, and external CSS. I also practiced element, class, and ID selectors.

## Part 4 - Intermediate CSS
I practiced CSS styling, including margins, padding, borders, sizing, and positioning.

## Summary
In this assignment, I learned how HTML structures a webpage and how CSS can be used to change its appearance and layout.
